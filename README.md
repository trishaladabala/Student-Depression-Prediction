# Student Depression Prediction

This project leverages the **Student Depression Dataset** from Kaggle to develop a machine learning model aimed at predicting depression levels among students based on various factors.

[Dataset on Kaggle](https://www.kaggle.com/datasets/hopesb/student-depression-dataset)

## 🎯 Objective

The goal is to accurately predict whether a student is experiencing depression using survey data encompassing academic, social, and health-related factors.

## 📊 Dataset Overview

The dataset includes responses related to:

- Academic performance
- Family background
- Social behavior
- Mental and physical health
- Lifestyle habits

Each entry represents an individual student's responses, with the target variable indicating their depression status.

## 🔍 Exploratory Data Analysis (EDA)

- **Data Cleaning:** Addressed missing and inconsistent values.
- **Visualization:** Explored feature distributions and relationships.
- **Encoding:** Transformed categorical variables into numerical formats.
- **Normalization:** Scaled numerical features to ensure uniformity.

## 🧠 Modeling Approach

Machine learning algorithm used

- Logistic Regression

The best-performing model achieved an **accuracy of 84.9%**, indicating robust predictive capabilities.
